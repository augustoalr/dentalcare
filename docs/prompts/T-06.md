2. **Tabla `public.patient_files` (esquema canónico de `docs/ARQUITECTURA.md`):**
   - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`
   - `clinic_id uuid NOT NULL REFERENCES public.clinics(id) ON DELETE RESTRICT`
   - `patient_id uuid NOT NULL`
   - `appointment_id uuid` *(nullable por ahora; la FK a `public.appointments(id)` se añadirá en `T-08`)*
   - `storage_path text NOT NULL UNIQUE` con `CHECK`:
     - Debe coincidir exactamente con el patrón `clinic_id::text || '/' || patient_id::text || '/'` seguido de un UUID v4 en minúsculas y una extensión permitida (`jpg`, `png`, `webp`, `pdf`):
       ```sql
       storage_path = lower(clinic_id::text || '/' || patient_id::text || '/') || substring(storage_path FROM '^[^/]+/[^/]+/([0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}\.(jpg|png|webp|pdf))$')
       ```
       *(o equivalente booleano estricto con `~` y prefijo exacto que garantice cero `..`, cero barras extra, extensión alineada y vínculo exacto `clinic_id/patient_id/<uuid>.<ext>`).*
   - `file_name text NOT NULL CHECK (length(trim(file_name)) > 0 AND length(file_name) <= 255)` *(longitud cruda `length(file_name)`, sin permitir espacios extra más allá de 255)*
   - `mime_type text NOT NULL CHECK (mime_type IN ('image/jpeg', 'image/png', 'image/webp', 'application/pdf'))`
   - `file_size_bytes bigint NOT NULL CHECK (file_size_bytes > 0 AND file_size_bytes <= 10485760)` *(máx. 10 MB = 10 485 760 bytes)*
   - `uploaded_by uuid NOT NULL REFERENCES auth.users(id) ON DELETE RESTRICT`
   - `created_at timestamptz NOT NULL DEFAULT now()`
   - `updated_at timestamptz NOT NULL DEFAULT now()`
   - `deleted_at timestamptz`
   - Restricción FK compuesta:
     `CONSTRAINT patient_files_clinic_patient_fkey FOREIGN KEY (clinic_id, patient_id) REFERENCES public.patients (clinic_id, id) ON DELETE RESTRICT`
