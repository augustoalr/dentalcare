### 3. Motor financiero bimoneda puro con `BigInt` (`src/domain/money.ts` y `src/domain/money.test.ts`)
**PROHIBIDO** usar coma flotante (`Number(x) * rate`, `Math.round(x / rate)`). Todo cálculo usa exclusivamente `BigInt`:
- Constantes alineadas 1:1 con SQL:
  - `EXCHANGE_RATE_SCALE = 1_000_000`
  - `MIN_EXCHANGE_RATE_MICROS = 1`
  - `MAX_EXCHANGE_RATE_MICROS = 999_999_999_999_999`
- Tipos inmutables:
  - `DualCurrencyConfig`: `{ readonly secondaryCurrencyCode: string; readonly secondaryCurrencySymbol: string; readonly exchangeRateMicros: number; readonly exchangeRateUpdatedAt: string | null }`
  - `DualCurrencyUpdateInput`: `{ readonly enabled: false } | { readonly enabled: true; readonly secondaryCurrencyCode: string; readonly secondaryCurrencySymbol: string; readonly exchangeRateMicros: number }`
  - `RawDualCurrencyInput`: `{ readonly enabled: boolean; readonly secondaryCurrencyCode: string; readonly secondaryCurrencySymbol: string; readonly exchangeRateMicros: number | null }`
  - `DualCurrencyFieldErrors` y `DualCurrencyValidationResult` (códigos de error tipados, incluyendo `secondary_currency_same_as_primary` y `exchange_rate_invalid`).
  - `DualFormattedMoney`: `{ readonly primaryFormatted: string; readonly secondaryFormatted: string | null; readonly secondaryCents: number | null }`
- Funciones puras:
  - `exchangeRateStringToMicros(rawRate: string): number | null`:
    - Acepta enteros y decimales con `.` o `,` de hasta **6 decimales** (ej. `"52"` → `52_000_000`, `"52.35"` → `52_350_000`, `"52,3456"` → `52_345_600`, `"0.92"` → `920_000`, `"0.000001"` → `1`, `"00036.50"` → `36_500_000`).
    - Rechaza (`null`): vacío, `"0"`, `"0.000000"`, negativos, `> 6` decimales (`"52.1234567"`), incompletos (`".5"`, `"5."`), múltiples separadores (`"1,234.56"`), letras o valores `> MAX_EXCHANGE_RATE_MICROS`.
  - `microsToExchangeRateString(rateMicros: number, minDecimals: number = 2): string`:
    - División entera `BigInt` (`52_000_000` → `"52.00"`, `52_345_600` → `"52.3456"`, `1` → `"0.000001"`, `920_000` → `"0.92"`), recortando ceros sobrantes a la derecha sin bajar de `minDecimals` (`0..6`). Lanza `RangeError` si `rateMicros` o `minDecimals` son inválidos.
  - `formatExchangeRateDisplay(primaryCurrencyCode: string, secondaryCurrencySymbol: string, rateMicros: number, locale: SupportedLocale): string`:
    - Formatea legiblemente en EN/ES con separadores de miles y decimal localizados (ej. `es`: `1 USD = Bs. 52,35` o `1 USD = Bs. 52,3456`; `en`: `1 USD = Bs. 52.35`).
  - `convertPrimaryToSecondaryCents(primaryCents: number, exchangeRateMicros: number): number`:
    - Aritmética pura `BigInt` con redondeo simétrico half-up exacto (`quotient = numerator / 1_000_000n`, `remainder = numerator % 1_000_000n`, redondeo hacia arriba si `remainder * 2n >= 1_000_000n`). Valida que entrada y salida sean enteros seguros (`RangeError` si desbordan `Number.MAX_SAFE_INTEGER`).
  - `convertSecondaryToPrimaryCents(secondaryCents: number, exchangeRateMicros: number): number`:
    - Aritmética pura `BigInt` con redondeo simétrico half-up exacto (`numerator = absSecondaryCents * 1_000_000n`, `divisor = BigInt(exchangeRateMicros)`, `quotient = numerator / divisor`, `remainder = numerator % divisor`, redondeo hacia arriba si `remainder * 2n >= divisor`). Valida enteros seguros.
  - `formatDualMoney(primaryCents: number, primaryConfig: CurrencyDisplayConfig, dualCurrency: DualCurrencyConfig | null, locale: SupportedLocale): DualFormattedMoney`:
    - Devuelve `{ primaryFormatted, secondaryFormatted: null, secondaryCents: null }` cuando `dualCurrency === null` (clínicas de 1 moneda), o ambos valores formateados cuando está activo.
  - `validateDualCurrencyInput(raw: RawDualCurrencyInput, primaryCurrencyCode: string): DualCurrencyValidationResult`:
    - Si `!raw.enabled`, devuelve `{ valid: true, value: { enabled: false }, ... }`.
    - Si `raw.enabled`, normaliza `secondaryCurrencyCode` (`trim().toUpperCase()`), valida regex `^[A-Z]{3}$`, rechaza si coincide con `primaryCurrencyCode.trim().toUpperCase()` (`secondary_currency_same_as_primary`), valida `secondaryCurrencySymbol` `1..10` y `exchangeRateMicros` entero seguro `1..MAX_EXCHANGE_RATE_MICROS`.
  - Helper `getClinicDualCurrencyConfig(clinic)`: construye `DualCurrencyConfig | null` seguro a partir de los 4 campos de `ClinicSummary` (devuelve `null` si cualquiera de los 3 campos de config es `null`/`undefined`).
