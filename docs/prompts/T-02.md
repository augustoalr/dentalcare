### 2. Migración SQL idempotente (`supabase/migrations/202611250001_base_schema_rls.sql`)
Debe ser **idempotente** (ejecutarla 2 veces seguidas no produce error) y compatible con **PostgreSQL 17 / Supabase** sin incluir stubs de `auth` dentro de la migración de producción:

1. **Tablas y restricciones (`public`):**
   - `public.clinics`:
     - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`
     - `name text NOT NULL CHECK (length(trim(name)) > 0)`
     - `currency_code text NOT NULL DEFAULT 'AED' CHECK (currency_code ~ '^[A-Z]{3}$')`
     - `currency_symbol text NOT NULL DEFAULT 'AED' CHECK (length(trim(currency_symbol)) > 0)`
     - `tax_rate_bps integer NOT NULL DEFAULT 500 CHECK (tax_rate_bps >= 0 AND tax_rate_bps <= 10000)`
     - `tax_label text NOT NULL DEFAULT 'VAT' CHECK (length(trim(tax_label)) > 0)`
     - `timezone text NOT NULL DEFAULT 'Asia/Dubai' CHECK (length(trim(timezone)) > 0)`
     - `default_locale text NOT NULL DEFAULT 'en' CHECK (default_locale IN ('en', 'es'))`
     - `created_at timestamptz NOT NULL DEFAULT now()`
     - `updated_at timestamptz NOT NULL DEFAULT now()`
     - `deleted_at timestamptz`
   - `public.profiles`:
     - `id uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE RESTRICT`
     - `clinic_id uuid NOT NULL REFERENCES public.clinics(id) ON DELETE RESTRICT`
     - `full_name text NOT NULL CHECK (length(trim(full_name)) > 0)`
     - `role text NOT NULL CHECK (role IN ('admin', 'dentist', 'receptionist'))`
     - `preferred_locale text NOT NULL DEFAULT 'en' CHECK (preferred_locale IN ('en', 'es'))`
     - `is_active boolean NOT NULL DEFAULT true`
     - `created_at timestamptz NOT NULL DEFAULT now()`
     - `updated_at timestamptz NOT NULL DEFAULT now()`
     - `deleted_at timestamptz`
   - `public.audit_log`:
     - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`
     - `clinic_id uuid NOT NULL REFERENCES public.clinics(id) ON DELETE RESTRICT`
     - `actor_id uuid NOT NULL REFERENCES auth.users(id) ON DELETE RESTRICT`
     - `action text NOT NULL CHECK (length(trim(action)) > 0)`
     - `entity_type text NOT NULL CHECK (length(trim(entity_type)) > 0)`
     - `entity_id uuid`
     - `metadata_json jsonb NOT NULL DEFAULT '{}'::jsonb`
     - `created_at timestamptz NOT NULL DEFAULT now()`
     - *(SIN `deleted_at` ni `updated_at`.)*

2. **Índices para RLS y consultas frecuentes:**
   - `idx_profiles_clinic_id` en `public.profiles (clinic_id)`
   - `idx_profiles_clinic_role` en `public.profiles (clinic_id, role)`
   - `idx_audit_log_clinic_created_at` en `public.audit_log (clinic_id, created_at DESC)`

3. **Funciones auxiliares en esquema no expuesto (`private`):**
   - `CREATE SCHEMA IF NOT EXISTS private;`
   - `private.current_clinic_id() RETURNS uuid` (`LANGUAGE sql STABLE SECURITY DEFINER SET search_path = ''`): retorna `clinic_id` de `public.profiles` donde `id = (select auth.uid()) AND is_active = true AND deleted_at IS NULL`.
   - `private.current_user_role() RETURNS text` (`LANGUAGE sql STABLE SECURITY DEFINER SET search_path = ''`): retorna `role` con el mismo filtro de usuario activo y no borrado.
   - `private.is_clinic_admin() RETURNS boolean` (`LANGUAGE sql STABLE SECURITY DEFINER SET search_path = ''`): retorna `true` solo si existe perfil activo no borrado para `(select auth.uid())` con `role = 'admin'`.
   - Permisos mínimos en `private`:
     - `REVOKE ALL ON SCHEMA private FROM PUBLIC, anon, authenticated;`
     - `GRANT USAGE ON SCHEMA private TO authenticated;`
     - `REVOKE ALL ON FUNCTION private.current_clinic_id(), private.current_user_role(), private.is_clinic_admin() FROM PUBLIC, anon, authenticated;`
     - `GRANT EXECUTE ON FUNCTION private.current_clinic_id(), private.current_user_role(), private.is_clinic_admin() TO authenticated;`

4. **Triggers de integridad, inmutabilidad y anti-escalada de privilegios:**
   - `private.set_updated_at()` (`BEFORE UPDATE` en `clinics` y `profiles`): actualiza `NEW.updated_at = now()`.
   - `private.guard_profile_update()` (`BEFORE UPDATE` en `public.profiles`):
     - Bloquea siempre cambiar `id` o `clinic_id` (`IF NEW.id IS DISTINCT FROM OLD.id OR NEW.clinic_id IS DISTINCT FROM OLD.clinic_id THEN RAISE EXCEPTION ... USING ERRCODE = '42501'; END IF;`) cuando `current_user = 'authenticated'`.
     - Si `current_user = 'authenticated'` y `NOT private.is_clinic_admin()`, bloquea cualquier cambio en `role`, `full_name`, `is_active` o `deleted_at` (código `42501`), permitiendo únicamente editar su propio `preferred_locale`.
   - `private.prevent_audit_log_mutation()` (`BEFORE UPDATE OR DELETE` en `public.audit_log`): SIEMPRE lanza `RAISE EXCEPTION 'audit_log is strictly immutable' USING ERRCODE = '42501';`.

5. **RLS + `FORCE ROW LEVEL SECURITY` + `GRANT` mínimos explícitos:**
   - Activar `ALTER TABLE ... ENABLE ROW LEVEL SECURITY;` y `ALTER TABLE ... FORCE ROW LEVEL SECURITY;` en `clinics`, `profiles` y `audit_log`.
   - `REVOKE ALL ON public.clinics, public.profiles, public.audit_log FROM PUBLIC, anon, authenticated;`
   - `GRANT` mínimos a `authenticated` (y ninguno a `anon`):
     - `GRANT SELECT, UPDATE ON public.clinics TO authenticated;`
     - `GRANT SELECT, INSERT, UPDATE ON public.profiles TO authenticated;`
     - `GRANT SELECT, INSERT ON public.audit_log TO authenticated;`
   - Políticas RLS (siempre envolviendo llamadas en `(select ...)` para rendimiento `initPlan`, restringidas `TO authenticated`):
     - **`clinics`:**
       - `SELECT`: `id = (select private.current_clinic_id()) AND deleted_at IS NULL`
       - `UPDATE`: `USING (id = (select private.current_clinic_id()) AND (select private.is_clinic_admin()) AND deleted_at IS NULL)` y `WITH CHECK (id = (select private.current_clinic_id()))`
     - **`profiles`:**
       - `SELECT`: `clinic_id = (select private.current_clinic_id()) AND deleted_at IS NULL`
       - `INSERT`: `WITH CHECK (clinic_id = (select private.current_clinic_id()) AND (select private.is_clinic_admin()))`
       - `UPDATE`: `USING (clinic_id = (select private.current_clinic_id()) AND deleted_at IS NULL AND ((select private.is_clinic_admin()) OR id = (select auth.uid())))` y `WITH CHECK (clinic_id = (select private.current_clinic_id()) AND ((select private.is_clinic_admin()) OR id = (select auth.uid())))`
     - **`audit_log`:**
       - `SELECT`: `clinic_id = (select private.current_clinic_id()) AND (select private.is_clinic_admin())`
       - `INSERT`: `WITH CHECK (clinic_id = (select private.current_clinic_id()) AND actor_id = (select auth.uid()))`
       - Sin políticas `UPDATE` ni `DELETE`.
