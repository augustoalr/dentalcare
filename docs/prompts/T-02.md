4. **Triggers de integridad, inmutabilidad y anti-escalada (OBLIGATORIO `SECURITY INVOKER` + `SET search_path = ''`):**
   Todas las funciones trigger deben declararse explícitamente con **`SECURITY INVOKER`** y **`SET search_path = ''`** (cualificando `pg_catalog.now()`, `pg_catalog.to_jsonb()`, `auth.uid()`, `private.*`), y con `REVOKE ALL ON FUNCTION ... FROM PUBLIC, anon, authenticated` para impedir llamadas directas:
   - `private.set_updated_at()` (`BEFORE UPDATE` en `public.clinics` y `public.profiles`): actualiza `NEW.updated_at := pg_catalog.now();`.
   - `private.guard_clinic_update()` (`BEFORE UPDATE` en `public.clinics`):
     - Bloquea siempre (para cualquier rol) cambios en `id` o `created_at` (`RAISE EXCEPTION ... USING ERRCODE = '42501'`).
   - `private.guard_profile_update()` (`BEFORE UPDATE` en `public.profiles`):
     - Bloquea siempre (para cualquier rol) cambios en `id`, `clinic_id` o `created_at` (`ERRCODE = '42501'`).
     - Cuando `current_user IN ('authenticated', 'anon')`:
       - Si `NOT private.is_clinic_admin()`: exige `OLD.id = (select auth.uid())` y aplica **lista blanca estricta** (solo se pueden modificar `preferred_locale` y `updated_at`), rechazando cualquier otro cambio con `ERRCODE = '42501'`:
         `IF (pg_catalog.to_jsonb(NEW) - 'preferred_locale' - 'updated_at') IS DISTINCT FROM (pg_catalog.to_jsonb(OLD) - 'preferred_locale' - 'updated_at') THEN RAISE EXCEPTION ... USING ERRCODE = '42501'; END IF;`
       - Si `OLD.id = (select auth.uid()) AND OLD.role = 'admin'`: bloquea auto-desactivación (`NEW.is_active = false`), auto-borrado (`NEW.deleted_at IS NOT NULL`) o cambio de su propio `role` (`NEW.role IS DISTINCT FROM OLD.role`), lanzando `ERRCODE = '42501'` para impedir dejar la clínica sin administrador.
   - `private.enforce_audit_log_defaults()` (`BEFORE INSERT` en `public.audit_log`): fuerza `NEW.created_at := pg_catalog.now();` para impedir falsificación de timestamps.
   - `private.prevent_audit_log_mutation()`: SIEMPRE lanza `RAISE EXCEPTION 'audit_log is strictly immutable' USING ERRCODE = '42501';`. Asociarla mediante **dos triggers** en `public.audit_log`:
     - `CREATE OR REPLACE TRIGGER trg_audit_log_no_mutation BEFORE UPDATE OR DELETE ON public.audit_log FOR EACH ROW EXECUTE FUNCTION private.prevent_audit_log_mutation();`
     - `CREATE OR REPLACE TRIGGER trg_audit_log_no_truncate BEFORE TRUNCATE ON public.audit_log FOR EACH STATEMENT EXECUTE FUNCTION private.prevent_audit_log_mutation();`

RETURNING *` / `.update().select()` sin error `42501`, manteniendo ocultos los borrados para `dentist`/`receptionist`).*
