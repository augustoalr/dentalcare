### 2. Dominio puro anti-fuga de WhatsApp (`src/domain/whatsapp.ts` y `src/domain/whatsapp.test.ts`)
Sin imports de React ni Supabase; 100% inmutable y con **lista blanca estricta** (R-12):
- **Normalización de teléfono (`normalizePhoneForWhatsApp(rawPhone: string | null | undefined): string | null`):**
  - Elimina espacios, guiones, paréntesis y puntos; elimina prefijo `+` o `00` inicial.
  - Valida formato estricto de dígitos E.164: `^[1-9][0-9]{6,14}$` (7 a 15 dígitos, sin ceros iniciales tras retirar `00`). Cualquier teléfono vacío, con letras, demasiado corto o inválido devuelve `null`.
- **Nombre de pila (`extractPatientFirstName(fullName: string): string`):**
  - Devuelve únicamente el primer token tras `trim()` (`split(/\s+/)[0]`, acotado a 40 caracteres), nunca apellidos completos ni datos adicionales.
- **DTO estrictamente acotado (`WhatsAppReminderPayload`):**
  ```ts
  export interface WhatsAppReminderPayload {
    readonly recipientPhoneE164Digits: string;
    readonly patientFirstName: string;
    readonly clinicName: string;
    readonly appointmentDateLabel: string;
    readonly appointmentTimeLabel: string;
    readonly locale: SupportedLocale;
  }
  ```
- **Constructor seguro (`buildSafeAppointmentReminderPayload`):**
  - Acepta **únicamente** `{ patientFullName, patientPhone, clinicName, startsAtIso, timezone, locale }` — **NUNCA** recibe `medicalAlerts`, `reason`, `clinicalNotes`, `generalNotes`, `dateOfBirth` ni `email`.
  - Formatea `appointmentDateLabel` y `appointmentTimeLabel` en `clinic.timezone` y `locale` (`en` / `es`) usando helpers puros de `src/domain/appointments.ts` (`extractClinicDateAndTime`, `formatScheduleDateLabel` y formateo de hora `HH:mm` / `Intl.DateTimeFormat` en `safeTimezone`).
  - Devuelve `null` si el teléfono es inválido, el nombre/clínica están vacíos o la fecha es inválida.
- **Plantillas de mensaje (`formatAppointmentReminderMessage(payload: WhatsAppReminderPayload): string`):**
  - `es`: `Hola {firstName}, te recordamos tu cita en {clinicName} el {date} a las {time}. Por favor responde para confirmar.`
  - `en`: `Hello {firstName}, this is a reminder for your appointment at {clinicName} on {date} at {time}. Please reply to confirm.`
  - Garantizado: contiene **ÚNICAMENTE** nombre de pila, clínica, fecha y hora (cero motivo, cero diagnóstico, cero alertas médicas, cero notas clínicas).
- **Constructor de URL (`buildWaMeReminderUrl(payload: WhatsAppReminderPayload): string`):**
  - Valida `recipientPhoneE164Digits` contra `^[1-9][0-9]{6,14}$` (lanzando `Error` si es inválido) y construye `https://wa.me/${payload.recipientPhoneE164Digits}?text=${encodeURIComponent(message)}`.
- **Elegibilidad (`getAppointmentReminderEligibility(appointment, patient)`):**
  - Elegible únicamente si `appointment.status === 'scheduled' || appointment.status === 'confirmed'` **y** `normalizePhoneForWhatsApp(patient?.phone) !== null`.
  - Devuelve `{ eligible: true, normalizedPhoneDigits }` o `{ eligible: false, reason: 'status_not_eligible' | 'missing_or_invalid_phone' }`.
- **Formateo de `reminderSentAt`:** helper puro `formatReminderSentTime(reminderSentAtIso: string, timezone: string, locale: SupportedLocale): string` para mostrar la hora/fecha legible del último recordatorio enviado en la zona horaria de la clínica.
